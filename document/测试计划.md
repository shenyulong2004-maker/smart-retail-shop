# smart-retail-shop 电商系统测试计划

## 一、项目概述

### 1.1 项目背景

smart-retail-shop 是一套 B2C 电商系统，包含前台商城系统（mall-portal）与后台管理系统（mall-admin）两大端。前台面向消费者，提供商品浏览、搜索、购物车、下单支付、会员中心等功能；后台面向运营人员，提供商品、订单、会员、促销、内容等管理功能。

### 1.2 技术栈

- **后端：** Spring Boot 3.5 + JDK 17 + MyBatis + Spring Security + JWT
- **存储：** MySQL 5.7 + Redis 7.0 + MongoDB 5.0 + MinIO
- **中间件：** RabbitMQ 3.10.5 + Elasticsearch 7.17.3 + Logstash + Kibana
- **部署：** Docker + Docker Compose + Nginx + Jenkins
- **接口文档：** SpringDoc（OpenAPI 3）

### 1.3 测试目标

- 验证系统各模块功能符合需求规格，核心业务流程可正常流转
- 验证后台管理 31 个 Controller、前台商城 13 个 Controller 的接口可用性
- 通过自动化测试覆盖核心回归场景，提升迭代效率
- 发现并跟踪缺陷至闭环，保证系统上线质量

### 3.2 功能测试策略

采用**等价类划分、边界值分析、场景法、错误推测法**设计用例，重点关注：

- **正向流程：** 验证核心业务主流程可走通
- **逆向流程：** 异常输入、空值、超长字符、特殊字符
- **业务规则：** 库存扣减、优惠券规则、会员等级、价格阶梯
- **权限控制：** 未登录访问、越权访问、Token 失效
- **数据校验：** 数据库落库正确性、缓存与 DB 一致性

### 3.4 自动化测试策略

- 覆盖 P0 级核心回归用例，减少手工回归成本

#### 3.4.5 自动化接入 CI

- **Jenkins Job 配置：** 拉取代码 → Maven 编译 → 执行 testng.xml → 生成 Allure 报告

- **报告通知：** Allure 报告归档 + 飞书/钉钉机器人推送结果
